# English checkpoint

The 20,000-step checkpoint (~420 MB) is hosted on Hugging Face, not in this repo:

- https://huggingface.co/rohan1822/fastspeech2-tts-checkpoints/resolve/main/English/20000.pth.tar
- Universal HiFi-GAN vocoder: https://huggingface.co/rohan1822/fastspeech2-tts-checkpoints/resolve/main/vocoder/generator_universal.pth.tar

Place the checkpoint at `output/ckpt/English/20000.pth.tar` and the vocoder at `hifigan/generator_universal.pth.tar`.
